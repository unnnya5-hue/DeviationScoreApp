# 偏差値おもちゃアプリ

若者向けに、さまざまなテーマの「偏差値」を簡易診断できる iOS アプリです。

## ドキュメント

- [要件定義書](docs/requirements.md)

## 初期方針

- iOS / SwiftUI で実装
- MVPではログイン、ランキング、広告、課金は後回し
- 診断データはアプリ内の静的データから開始
- 診断履歴は端末内保存から開始

## MVP

- トップ画面
- 偏差値一覧画面
- 診断画面
- 結果画面
- SNSシェア
- 診断履歴
