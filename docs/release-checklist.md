## 収益化のおすすめ順

1. 初回リリースは結果画面と診断一覧のバナー広告だけにする
2. ユーザー反応を見て、診断完了後など自然な区切りでインタースティシャル広告を少量だけ試す
3. 広告が体験を壊す場合は、広告非表示の買い切り課金を検討する
