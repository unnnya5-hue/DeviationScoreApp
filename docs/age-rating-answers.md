# 年齢レーティング回答案

最終更新日: 2026-05-18

## 前提

「いろいろ偏差値診断」は、エンターテインメント目的の簡易診断アプリです。

- 暴力表現なし
- 性的表現なし
- ギャンブルなし
- ユーザー生成コンテンツなし
- Webブラウザ機能なし
- 位置情報共有なし
- 医療・治療情報なし
- 課金なし
- ログインなし

「恋愛」「婚活」テーマはありますが、露骨な性的表現や成人向けコンテンツは含めない前提です。

## 回答案

App Store Connectの質問文は時期により変わる可能性があるため、画面上の文言に合わせて読み替えてください。

| 質問カテゴリ | 回答案 |
| --- | --- |
| まれ、軽度の過激な言葉または下品なユーモア | なし |
| まれ、軽度の成人向けまたは性的なテーマ | なし |
| 頻繁、極度の成人向けまたは性的なテーマ | なし |
| まれ、軽度の暴力表現 | なし |
| 頻繁、極度の暴力表現 | なし |
| 医療または治療情報 | なし |
| アルコール、タバコ、薬物の使用または言及 | なし |
| ギャンブルまたはコンテスト | なし |
| 無制限のWebアクセス | なし |
| ユーザー生成コンテンツ | なし |
| 個人情報または位置情報の共有 | なし |

## 年齢制限の見込み

この回答なら、低い年齢レーティングになる見込みです。ただし、最終的な年齢レーティングはApp Store Connectの回答結果に従います。

## 注意

以下のような文言や機能を追加した場合は、回答を見直します。

- 露骨な性的表現
- 飲酒、喫煙、薬物を肯定する表現
- 暴力的な表現
- ユーザー投稿、コメント、ランキング名入力などのUGC
- 外部Webページを自由に閲覧できる機能
- 位置情報共有
