# スクリーンショット準備

最終更新日: 2026-05-18

## 方針

初回リリースはiPhone専用のため、まずiPhone向けスクリーンショットを用意します。

Appleのスクリーンショット仕様に従い、App Store Connectに必要なサイズをアップロードします。実機またはシミュレーターで撮影し、広告が大きく被る場合は撮影タイミングをずらします。自分の本番広告はクリックしません。

## 撮影候補

1. トップ画面
2. 診断一覧画面
3. 診断中の選択式質問
4. IQ風クイズまたは数字入力画面
5. 結果画面
6. 履歴画面

## 推奨構成

### 1枚目: トップ画面

見せたいもの:

- アプリ名「偏差値あそび」
- 診断数や雰囲気
- ファニーなデザイン

### 2枚目: 診断一覧画面

見せたいもの:

- 診断テーマの多さ
- 恋愛、IQ風、コミュ力、仕事、ネタ系などの幅

### 3枚目: 診断中の選択式質問

見せたいもの:

- 質問に答えるゲーム感
- 進捗表示
- 選択式UI

### 4枚目: 数字入力またはIQ風クイズ

見せたいもの:

- 数字入力あり
- IQ風クイズのタイマー
- 単なる選択式だけではない点

### 5枚目: 結果画面

見せたいもの:

- 偏差値スコア
- 判定コメント
- SNSシェアボタン

### 6枚目: 履歴画面

見せたいもの:

- 過去の結果確認
- 履歴から結果画面を再表示できる導線

## 撮影前チェック

- 本番AdMob IDでクラッシュしない
- 広告が読み込まれない場合でもUIが崩れない
- スクショ内に開発用の `TEST` 表示が出ていない
- 個人情報や不要な通知が映っていない
- ステータスバーの時刻やバッテリー表示が不自然でない
- 文字切れ、重なり、ボタンのはみ出しがない

## 保存先

撮影した画像は以下に保存します。

```text
docs/screenshots/app-store/
```

## Xcode / Simulatorでの撮影手順

1. Xcodeで `DeviationScoreApp` を開く
2. iPhone 17など、提出用に近いiPhone Simulatorを選ぶ
3. `Product > Run` で起動
4. 各画面へ移動
5. Simulatorのスクリーンショット機能、または `xcrun simctl io booted screenshot` で撮影
6. `docs/screenshots/app-store/` に整理

## App Store Connect登録時の注意

- iPhone用スクリーンショットを優先して登録
- iPad非対応なのでiPadスクリーンショットは不要
- スクショはアプリの実画面と一致させる
- 説明文に書いている機能がスクショでも伝わるようにする
