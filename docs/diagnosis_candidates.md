## 診断を追加するときの手順

1. **問題案を書く**: `tools/diagnosis/source/*.txt` に追記します（書式は下記）。
2. **レビュー資料を作る**: `python3 tools/diagnosis/gen_review.py` を実行すると、`docs/new_diagnosis_questions_review.md` と `docs/new_diagnosis_questions_editable.json` が更新されます。
3. **収録する診断を決める**: `tools/diagnosis/releases/<バージョン>.txt` に診断IDを空白区切りで書きます（例: `releases/v1.2.txt`）。
4. **アプリに取り込む**: `python3 tools/diagnosis/gen_swift.py v1.2` を実行します。
   - `DiagnosisCatalog.swift` の末尾に診断が追記されます。
   - NEWバッジの対象（`newDiagnosisIDs`）が、そのリリースの診断に入れ替わります。
5. **このファイルを更新**: 状態を 📝/💡 → ✅ に移し、リリースしたら ✅ → 🟢 に移します。
6. もう一度 `gen_review.py` を実行して、レビュー資料の「状態」を更新します。

### 問題ソースの書式（`tools/diagnosis/source/*.txt`）

```
# 診断ID|タイトル|短いタイトル|カテゴリ|概要
N|質問文|単位|range|理想の下限|理想の上限|0点になる下限|0点になる上限
N|質問文|単位|higher|0点の値|満点の値
N|質問文|単位|lower|満点の値|0点の値
N|質問文|単位|exact|正解
N|質問文|単位|closest|正解|0点になる距離
C|質問文|4点の選択肢|3点|2点|1点
Q|質問文|正解（4点）|不正解（1点）|不正解（1点）|不正解（1点）
```

- 1診断あたり16問（`N` 5問＋`C`/`Q` 11問）にします。数が違うとスクリプトがエラーを出します。
- 選択肢の並び順は、スクリプトが質問IDを元に固定の順番でシャッフルします。
- カテゴリは 恋愛 / 知識 / コミュ力 / 仕事 / 就活 / お金 / 生活 / メンタル / センス / 趣味 / ネタ のいずれかです。

### そのほかの決まりごと

- 偏差値は高いほど「上手・強い」側にします。高いほどネタになる診断（陰の者など）は、`DiagnosisCatalog.swift` で専用の結果ランク（`bands`）を用意します。
- 正解のある問題は、事実確認をしてから収録します。年や制度で変わる問題にはメモを残します。
- タイマーを付けたい診断は、`DiagnosisFlowView.swift` の `tracksElapsedTime` にIDを追加します。
