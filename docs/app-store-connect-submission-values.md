### 説明

```text
「偏差値あそび」は、いろいろなテーマの偏差値を気軽に測って楽しむためのネタ診断アプリです。

婚活偏差値、IQ風クイズ偏差値、コミュ力偏差値、転職偏差値、就職偏差値、バズり偏差値、推し活偏差値など、日常のちょっとした話題にしやすい診断を収録しています。

各診断は16〜17問程度。選択式の質問だけでなく、数字入力や計算問題も混ぜながら、結果を偏差値風のスコアとして表示します。結果画面からSNSシェアもできるので、友達との会話やスクショネタとして楽しめます。

このアプリの診断結果は、エンタメ目的の簡易診断です。医学的、心理学的、学力的、職業適性上の正確な評価を目的としたものではありません。
```

## Appプライバシー回答方針

アプリ本体はログイン、外部サーバー送信、位置情報取得を行いません。診断履歴は端末内保存のみです。

ただし、Google Mobile Ads SDKを利用するため、App Store Connectでは第三者SDKによる収集データも含めて申告します。

### 申告候補

| データタイプ | 収集元 | 用途 |
| --- | --- | --- |
| ID > デバイスID | AdMob | 第三者広告、アナリティクス |
| 使用状況データ > 製品の操作 | AdMob | 第三者広告、アナリティクス |
| 使用状況データ > 広告データ | AdMob | 第三者広告、アナリティクス |
| 診断 > クラッシュデータ | AdMob | アプリ機能、アナリティクス |
| 診断 > パフォーマンスデータ | AdMob | アプリ機能、アナリティクス |
| 位置情報 > おおよその位置情報 | AdMob | 第三者広告、アナリティクス |

### トラッキング

初回リリースではATT許可ダイアログをまだ実装していないため、IDFAを前提にしたパーソナライズ広告は使わない方針が安全です。

App Store Connectの「トラッキングに使用されますか？」は、AdMob側でIDFAやパーソナライズ広告を利用する設定にするかで最終判断します。利用する場合は `NSUserTrackingUsageDescription` とATT許可ダイアログの実装が必要です。

## スクリーンショット

iPhone専用で提出するため、まずはiPhoneのスクリーンショットを用意します。Appleの案内では、UIが同じ場合は必要な高解像度スクリーンショットを用意すると小さいサイズへ流用できます。

候補:

1. トップ画面
2. 診断一覧画面
3. 診断中の選択式質問
4. 数字入力またはIQ風クイズ
5. 結果画面
6. 履歴画面
